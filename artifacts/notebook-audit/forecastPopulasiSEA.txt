## 3. Modelling LSTM

LSTM berikut memakai parameter yang identik dengan model LSTM forecast produksi beras. Parameter tersebut ditetapkan sebelum evaluasi test; model tetap di-fit menggunakan data populasi.


--- CELL 8 code ---
LSTM_PARAMS = {"lag": 3, "hidden": 8, "lr": 0.01, "weight_decay": 0.0001, "epochs": 250}
print("Parameter LSTM:", LSTM_PARAMS)

def supervised(values, lag):
    values = np.asarray(values, dtype=float)
    X = np.array([values[i-lag:i] for i in range(lag, len(values))])
    y = values[lag:]
    return X, y

class TinyLSTM(nn.Module):
    def __init__(self, hidden):
        super().__init__()
        self.lstm = nn.LSTM(1, hidden, batch_first=True)
        self.out = nn.Linear(hidden, 1)
    def forward(self, x):
        return self.out(self.lstm(x)[0][:, -1, :])

def fit_lstm_and_forecast(history, horizon, params=LSTM_PARAMS):
    scaler = MinMaxScaler()
    scaled = scaler.fit_transform(np.asarray(history, dtype=float).reshape(-1, 1)).ravel()
    X, y = supervised(scaled, params["lag"])
    X_tensor = torch.tensor(X[:, :, None], dtype=torch.float32)
    y_tensor = torch.tensor(y[:, None], dtype=torch.float32)

    torch.manual_seed(SEED)
    model = TinyLSTM(params["hidden"])
    optimizer = torch.optim.Adam(model.parameters(), lr=params["lr"],
                                 weight_decay=params["weight_decay"])
    loss_fn = nn.MSELoss()
    model.train()
    for _ in range(params["epochs"]):
        optimizer.zero_grad()
        loss = loss_fn(model(X_tensor), y_tensor)
        loss.backward()
        optimizer.step()

    model.eval()
    scaled_history, scaled_forecast = list(scaled), []
    with torch.no_grad():
        for _ in range(horizon):
            features = torch.tensor(np.array(scaled_history[-params["lag"]:])[None, :, None],
                                    dtype=torch.float32)
            prediction = model(features).item()
            scaled_history.append(prediction)
            scaled_forecast.append(prediction)
    return scaler.inverse_transform(np.array(scaled_forecast).reshape(-1, 1)).ravel()

def mape(y_true, y_pred):
    y_true, y_pred = np.asarray(y_true), np.asarray(y_pred)
    return np.mean(np.abs((y_true - y_pred) / y_true)) * 100

## Pemeriksaan leakage dan kesimpulan

Tidak ada kebocoran data: data train dan test dipisahkan secara kronologis, scaling diterapkan hanya pada data train, serta forecast test dibangun secara rekursif tanpa memasukkan aktual test sebagai fitur. Forecast 2025–2026 hanya dibuat setelah model di-fit ulang pada seluruh data aktual yang tersedia hingga 2024.
