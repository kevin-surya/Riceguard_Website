# Panel spatio-temporal produksi padi ASEAN

Notebook ini memakai dua tingkat analisis: panel **ASEAN penuh** tingkat negara untuk sembilan negara anggota yang memproduksi padi, serta panel ADM1 Indonesia–Filipina sebagai analisis resolusi tinggi. FAOSTAT tidak melaporkan seri padi untuk Singapura; negara tersebut tidak boleh diberi nilai nol buatan dan karenanya tidak termasuk model produksi padi.

Unit analisis ASEAN: `negara × tahun`, **2001–2023**; unit ADM1: `wilayah × tahun`, **2001–2018**. Produksi diukur dalam ton metrik, luas panen dalam hektare, dan yield dalam ton per hektare.

--- CELL 1 markdown ---
## Sumber dan batasan

- Panel ASEAN: [FAOSTAT Crops and livestock products](https://www.fao.org/faostat/en/#data/QCL), komoditas `Rice`, elemen produksi dan luas panen.
- Panel resolusi tinggi: [FAO Subnational Agricultural Production (ADM1)](https://data.fao.org/catalog/dataset/sub-national-agricultural-production-admin-level-1), komoditas `Rice`, metrik `Production (Metric Tonnes)` dan `Harvested Area (Hectares)`.
- Poligon: [GADM 4.1](https://gadm.org/data.html), ADM1. Kode `GID_1` FAO dan GADM digunakan untuk join.
- Kovariat iklim untuk ekstensi model: [CHIRPS](https://www.chc.ucsb.edu/data/chirps3), curah hujan grid 0,05° sejak 1981.

Jangan mencampurkan *paddy/rice* (gabah) dengan beras giling. Perubahan batas wilayah dapat memengaruhi seri; sel di bawah hanya mempertahankan unit yang teramati setiap tahun estimasi.

from libpysal.weights import KNN
from esda import Moran
import geopandas as gpd

def read_gadm_adm0(iso3):
    path = GADM_ADM0_DIR / f'gadm41_{iso3}_0.json.zip'
    if not path.exists(): raise FileNotFoundError(path)
    return gpd.read_file(path)[['GID_0', 'COUNTRY', 'geometry']].rename(columns={'GID_0': 'iso3'})

asean_geo = pd.concat([read_gadm_adm0(iso3) for iso3 in sorted(asean.iso3.unique())], ignore_index=True)
asean_geo = gpd.GeoDataFrame(asean_geo, geometry='geometry', crs='EPSG:4326').to_crs('EPSG:6933')
centroids = np.c_[asean_geo.geometry.centroid.x, asean_geo.geometry.centroid.y]
w_asean = KNN.from_array(centroids, k=3, ids=asean_geo.iso3.tolist()); w_asean.transform = 'R'
assert set(w_asean.id_order) == set(asean.iso3.unique())

moran_asean = []
for year, values in asean.groupby('year'):
    y = values.set_index('iso3').reindex(w_asean.id_order)['log_yield']
    stat = Moran(y.to_numpy(), w_asean, permutations=999)
    moran_asean.append({'year': year, 'moran_I': stat.I, 'p_sim': stat.p_sim, 'n': len(y)})
moran_asean = pd.DataFrame(moran_asean)
moran_asean.to_csv(PROCESSED / 'asean_country_moran_log_yield_2001_2023.csv', index=False)
display(moran_asean.describe())

## Baseline legacy 2030 (tidak digunakan untuk inferensi)

Forecast ini memakai proporsi padi grid 0,1° tahun 2000–2020. Komponen temporal adalah tren linear pada skala logit; komponen spasial adalah penghalusan Gaussian tetangga (aproksimasi ringan terhadap efek CAR). Ini adalah baseline *business-as-usual*, sehingga **bukan prediksi kausal** dan tidak memasukkan proyeksi hujan/suhu 2030. Untuk proyeksi berbasis skenario iklim, ganti atau tambahkan kovariat CMIP6/CHIRPS pada model.

--- CELL 15 code ---
from scipy.ndimage import gaussian_filter
from scipy.special import expit

MODEL_DIR = PROCESSED / 'raster_model'
historical = np.load(MODEL_DIR / 'apra500_sea_grid_0p1deg_2000_2020.npz')
years = historical['years']
rice_proportion = historical['rice_proportion']
assert rice_proportion.shape[0] == len(years) == 21

# Tren temporal grid-wise pada skala logit. Nilai kecil menjaga logit terdefinisi.
p = np.clip(rice_proportion, 1e-3, 1 - 1e-3)
z = np.log(p / (1 - p)); x = years - years.mean(); valid = np.isfinite(z)
n = valid.sum(axis=0); z_mean = np.nansum(z, axis=0) / np.maximum(n, 1)
slope = (np.nansum(np.where(valid, z - z_mean, 0) * x[:, None, None], axis=0) /
         np.maximum(np.nansum(valid * x[:, None, None]**2, axis=0), 1))
forecast_2030 = expit(z_mean + slope * (2030 - years.mean()))
forecast_2030[n < 15] = np.nan

# Efek spasial: rata-rata bertetangga berbobot Gaussian, tanpa mengisi laut/NoData.
mask = np.isfinite(forecast_2030).astype(float)
forecast_2030 = gaussian_filter(np.nan_to_num(forecast_2030) * mask, sigma=1, mode='nearest') / np.maximum(gaussian_filter(mask, sigma=1, mode='nearest'), 1e-6)
forecast_2030[mask == 0] = np.nan

summary_2030 = pd.read_csv(MODEL_DIR / 'apra500_sea_rice_grid_bau_2030_summary.csv')
display(summary_2030[['mean_rice_2000_2020', 'rice_probability_bau_2030']].describe())

DOWNLOAD_RAW = False  # ubah menjadi True untuk refresh dari FAO

def download_fao_metric(metric, destination, years=range(2001, 2024)):
    destination.mkdir(parents=True, exist_ok=True)
    for year in years:
        out = destination / f"rice_{metric.split()[0].lower()}_{year}.csv"
        params = {'crop': 'Rice', 'year': str(year), 'metric': metric,
                  'sql_url': FAO_SQL, 'download': 'true'}
        response = requests.get(FAO_API, params=params, timeout=120)
        response.raise_for_status()
        if not response.text.startswith('gid_1,'):
            raise ValueError(f'Format FAO tak dikenali pada {year}: {response.text[:100]}')
        out.write_text(response.text, encoding='utf-8')

if DOWNLOAD_RAW:

def read_metric(folder, value_name):
    files = sorted(folder.glob('*.csv'))
    if not files:
        raise FileNotFoundError(f'Tidak ada CSV di {folder}. Jalankan unduh dengan DOWNLOAD_RAW=True.')
    frame = pd.concat((pd.read_csv(file) for file in files), ignore_index=True)
    needed = {'gid_1', 'region_name', 'country_name', 'year', 'value'}
    missing = needed - set(frame.columns)
    if missing: raise ValueError(f'Kolom FAO hilang: {missing}')
    frame['iso3'] = frame['gid_1'].str.split('.').str[0]
    frame = frame[frame['iso3'].isin(COUNTRIES)].copy()
    # FAO kadang memuat revisi dari beberapa sumber untuk gid-tahun yang sama.
    # Prioritas Indonesia: BPS, lalu Kementerian Pertanian, lalu BDSP; Filipina: PSA.
    frame['source_rank'] = np.select([frame.source.str.contains('bps.go.id', na=False),
                                      frame.source.str.contains('pertanian.go.id', na=False),
                                      frame.source.str.contains('bdsp', na=False)], [0, 1, 2], default=0)
    frame = (frame.sort_values(['gid_1', 'year', 'source_rank'])
                  .drop_duplicates(['gid_1', 'year'], keep='first'))
    frame = frame.rename(columns={'value': value_name})
    return frame[['gid_1', 'region_name', 'country_name', 'iso3', 'year', value_name]]

def read_gadm_adm1(iso3):
    path = GADM_DIR / f'gadm41_{iso3}_1.json.zip'
    if not path.exists():
        raise FileNotFoundError(f'Batas GADM tidak ditemukan: {path}')

    country = panel[panel.iso3.eq(iso3)]
    available = gdf[gdf.gid_1.isin(country.gid_1.unique())].copy()
    w = Queen.from_dataframe(available, ids=available.gid_1.tolist()); w.transform = 'R'
